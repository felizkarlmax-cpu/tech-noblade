# JARVIS AI Assistant — Tech-Noblade

A local Python desktop voice assistant starter for Windows, designed to be extended with AI reasoning, PC automation, wake-word detection and a natural male voice.

## Requirements
- Windows 10/11 recommended
- Python 3.10+
- Working microphone and speakers

## Install
```powershell
git clone https://github.com/felizkarlmax-cpu/tech-noblade.git
cd tech-noblade
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
python jarvis.py
```

## Features
- Voice input
- Spoken responses
- Time/date
- Website opening/search
- Basic system information
- Safe exit handling
